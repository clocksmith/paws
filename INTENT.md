# INTENT: paws

Parent: none

## Need

Users and researchers need frozen context and proposed changes that can be exchanged faithfully without silently altering prompts, personas, or unrelated files.

## Target

Preserve deterministic CATS bundling, bounded DOGS application, and comparable research artifacts within the repository's archived status.

## Invariants

Keep bundle identifiers, ordering, and round-trip behavior stable. Protect authorized destination boundaries and existing user work. Prompt and persona semantics require explicit approval to change. Shared JavaScript and Python behaviors retain fixture compatibility.

## Evidence

Inspect bundle contents, application outputs, and the exact inputs behind an arena comparison. Use matching fixtures where both CLIs implement a behavior. A correct application does not establish that generated code solves the task or that historical model results remain current.

## Non-goals

No reopening the product roadmap, automatic repository ownership, dependency modernization campaign, or publication of a new release through governance changes.

## Truth

[README.md](README.md) records archive status; [packages/cli-js/README.md](packages/cli-js/README.md) describes CLI usage. Identified source, prompts, personas, and captured artifacts establish historical behavior. Preserve their limitations rather than upgrading old evidence through new wording.
